Three laws, three real functions

Learn by composing real conversions.

Every demo below uses genuine temperature-conversion functions — Celsius, Fahrenheit, and Kelvin form a small, honest category. Watch the same three laws that govern any category theory textbook play out in numbers you can check by hand.

Law 1 — Identity

Every object has a "do nothing" morphism.

For every object A, an identity morphism id_A : A → A exists, and composing it with any other morphism changes nothing: f ∘ id_A = f = id_B ∘ f. In code, this is the method that just returns this.

Click "Apply id_A" to see it leave the value unchanged.

Run the composite to see each step.

Law 2 — Composition

Composable morphisms always produce a third.

If f : C → F and g : F → K, their composite g ∘ f : C → K must exist and must be associative. Here it's not abstract — g∘f and the direct Celsius→Kelvin conversion h agree to the decimal, because both describe the same physical relationship.

Law 3 — Isomorphism

Some morphisms are perfectly reversible.

A morphism f : A → B is an isomorphism if there's an inverse f⁻¹ : B → A with f⁻¹ ∘ f = id_A and f ∘ f⁻¹ = id_B. Celsius and Fahrenheit are isomorphic objects: convert either way, then back, and you land exactly where you started.
